# SoloScale Skill Registry

This directory is the tracked source of reusable, bounded SoloScale workflows. Read `skills/registry.yaml` before inventing a workflow, then record selected versions and outcomes in the private Run Receipt. Runtime inputs, evidence bodies, generated private artifacts, and receipts belong under the ignored SoloScale data root, never here.

Initial definitions are either `DRAFT` or `CANDIDATE`; none is `ACTIVE`. `CANDIDATE`
means the underlying bounded capability exists and the Skill contract is ready for
representative Run validation. Promotion still follows the registry policy and requires
another representative success or explicit canonical human approval.
