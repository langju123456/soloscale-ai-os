# Conversation Distillation

Chat conversations are source material, not publication-ready records.

Do not commit raw private transcripts by default. Raw chats may include:

- credentials or personal data
- incorrect intermediate assumptions
- duplicated reasoning
- private commercial ideas
- unsupported claims
- context that does not belong in a public repository

For each valuable conversation, create a short distillation:

```markdown
# Conversation Distillation — <topic>

## Trigger
What question or friction started the discussion?

## New model
What mental model emerged?

## Decisions
Which decisions are now frozen?

## Rejected alternatives
What was considered and rejected?

## Open questions
What remains unresolved?

## Experiment
What will be built or measured next?

## Reusable language
Which phrases or diagrams are suitable for public narrative?
```

Store private raw exports outside Git. Commit only reviewed distillations.
