# 30-Day Execution Plan

## 总目标

30 天内证明两个闭环：

```text
Loop A：
真实工程任务 → Chat Plan → Codex → Tests → PR → Fresh Review → BuildLog

Loop B：
工程 Evidence → Script → Video Factory → 10 条内容 → Landing Page → Stripe Offer → 真实反馈
```

## Week 1 — Dogfood #1

### Day 1

- 将本手册加入 SoloScale Repo
- 创建 GitHub Project 与 Dogfood #1 Issue
- 确认目标 Repo、Branch 与验证命令

### Day 2

- ChatGPT 完成只读 Repo 分析
- 输出 Approved Plan、Risk Register、Test Plan
- 人工审批
- 生成 Codex Execution Packet

### Day 3–4

- Codex 只读兼容性检查
- Codex 最小实现
- Targeted tests
- 修复真实失败

### Day 5

- Full relevant verification
- Branch / Commit
- 创建 PR
- GitHub CI

### Day 6

- 新 ChatGPT 对话做独立审查
- Codex 只修 P0/P1
- 再次验证

### Day 7

- 接受/合并或记录阻塞
- SoloScale Evidence Pack
- BuildLog iteration
- Week 1 Retrospective

## Week 2 — Evidence-to-Narrative

产出：

```text
1 LinkedIn Case Study
1 X Thread
1 Architecture Carousel
3 Short Video Scripts
1 8–12 minute YouTube outline
```

同时建立：

- Claims ↔ Evidence Map
- Personal Brand Voice
- Company Brand Voice
- CTA 与 Offer 映射

## Week 3 — Creator Video Factory v0.1

Codex 只做本地工程：

```text
Remotion project
3 compositions
brand config
content manifest
subtitle generation
provenance
local render
tests
```

第一版输入使用 SoloScale clean-room evidence。

## Week 4 — Distribution & Revenue Test

- Render 第一批 10 条视频
- 人工选择 3–5 条发布
- 完成公司 Landing Page
- 创建一个免费 Lead Magnet
- 创建一个低价数字产品草案
- 创建 AI Workflow Audit 服务页
- 配置 Stripe Payment Link
- 开始记录平台和商业指标

## 三个并行 Lane

```text
Lane A：Engineering
Codex 一次只处理一个 Repo 写任务

Lane B：Strategy / Content
ChatGPT 可以同时准备下一任务和内容资产

Lane C：Plugins
Figma、GitHub、Vercel 等在线动作独立执行
```

## 30 天退出条件

```text
✓ 1 个完整 Dogfood 闭环
✓ 1 次真正 Fresh Review
✓ 3 个 Remotion 模板
✓ 10 条可发布视频
✓ 至少 3 条真实发布
✓ 公司 Landing Page
✓ 1 个免费资源
✓ 1 个 Stripe Offer
✓ 第一轮真实 Analytics
✓ 一个明确的下月瓶颈
```
