# DevLog — 2026-08-06 — Establish the v0.1 baseline

## Problem

The starter had implementation claims but no dated public record separating verified behavior from unresolved quality checks. Without a baseline, later remediation could erase the useful history of what was initially green and red.

## Evidence before change

The repository documentation described the v0.1 scope. A local verification run was needed to record command outcomes before remediation.

## Hypotheses

- The deterministic starter behavior is covered by the current tests.
- Type checking is clean at this revision.
- The CLI demo completes successfully.
- Lint may expose quality work not covered by behavior or type checks.

## Decision

Record every required command outcome, including failures. Do not describe the baseline as fully green while lint is failing, and do not claim remediation in this entry.

## Alternatives considered

- Record only passing checks: rejected because it would hide a known quality-gate failure.
- Wait until all checks pass: rejected because it would lose the pre-remediation baseline.

## Implementation

No source behavior changed in this baseline step. The local command outcomes were captured for the development record and launch claim ledger.

## Result

The tests, type check, and CLI demo passed at the recorded baseline. The lint quality gate did not pass: eight issues remained before remediation.

This result is implementation evidence only. It does not establish route accuracy on real workloads or prove improvements in time, context use, token use, cost, or output quality.

## Remaining risks

- Eight lint issues require separate remediation and verification.
- The command receipts need public CI or committed evidence links before numerical launch claims are published.
- No real feature has completed the full routed workflow.
- Efficiency and content-reuse claims remain unmeasured hypotheses.

## Lesson

A useful baseline preserves failures as well as passes. Evidence is strongest when it states both what a command proved and what it did not.
