# Sources & Tool Notes

本手册优先使用稳定的工作流边界，避免依赖容易变化的产品名称和价格。以下是当前官方参考点，购买或部署前应再次核验。

## OpenAI

- Apps / Plugins 可以把外部数据和动作带入 ChatGPT；可用性取决于 Plan、Workspace、Surface 和 App 能力。  
  https://help.openai.com/en/articles/11487775-connectors-in-chatgpt

- Plugins 可跨 ChatGPT 与 Codex 提供 Skills、Apps 与模板，但每项能力是否支持某个 Surface 要看插件详情。  
  https://help.openai.com/en/articles/20001256

- Codex Local 包含 CLI、IDE Extension 和 Desktop Local Workflows，适合本地工程执行。  
  https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan

- ChatGPT Projects 可作为持续上下文中心，保存聊天、文件与项目指令。  
  https://help.openai.com/en/articles/10169521-projects-in-chatgpt

## Video

- Remotion：React 程序化生成真实 MP4、参数化内容与批量渲染。  
  https://www.remotion.dev/

- Descript：屏幕、摄像头和麦克风录制，并通过 Transcript 编辑视频。  
  https://www.descript.com/screen-recording

- HeyGen：数字分身与语音能力，用于可选 Hook、CTA 或多语言片段。  
  https://www.heygen.com/avatars

- OpusClip：长视频切短、字幕、重构画幅和 Repurposing；也提供 MCP 入口。  
  https://www.opus.pro/  
  https://www.opus.pro/mcp

## 使用政策

- 先用免费/现有方案完成 10 条真实视频。
- 只为被测量到的瓶颈付费。
- 不克隆第三方创作者的脸、声音或独特身份。
- AI Avatar / AI Voice 的披露要求应按目标平台最新政策执行。
- 内容必须基于自己的工程证据、观点和分析。
